# Rem Scroll

PWA kecil untuk "rem" sebelum buka TikTok, IG Reels, Threads, YT Shorts.

- Gerbang: tunggu 10 detik, pilih kebutuhan, ganti aktivitas atau buka dengan batas waktu
- Timer fokus 15/25/45 menit
- Statistik harian, 7 hari, streak

Data disimpan di localStorage HP (tidak dikirim ke mana pun). Tanpa build: file statis.
